# Editor V1, source rights, and licensing

The original NextPhase Editor V1 ZIP is **not included** in this repository. It may be used privately to make personal and commercial videos under the distributor's license notes; do not resell or repackage the skill itself.

Set CLIPFORGE_EDITOR_V1_PATH to the privately installed folder containing SKILL.md. The current integration reports installation status and generates per-render JSON creative briefs. It does NOT yet run the third-party cinematic build scripts.

Footage research and timestamp lookup do not establish a right to download YouTube audiovisual streams. ClipForge's unattended rough-cut pipeline requires locally held, lawfully acquired video with explicit status and evidence. Unknown sources and proposed fair-use excerpts require human rights/editorial review. There is no universal fair-use-safe clip duration.

Future permissions: creators upload original footage, licensing contracts stored by reference, approved public-domain assets and reviewed excerpts with individualized commentary. Official APIs for publishing only.
